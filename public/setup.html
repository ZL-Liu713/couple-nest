OUR LITTLE SPACE · SETUP

让喜欢，跨过屏幕 💌

只需网站主人配置一次，两个人就可以用各自的手机同步互动。

当前体验版的消息仅保存在本机。完成下方配置后，才会真正连接到另一半。

01 · 准备共享的小窝

  1. 在 Supabase 创建项目。
  2. 打开 SQL Editor，运行源码包中的 supabase/schema.sql（新项目运行一次）。
  3. 启用 Email 登录，配置可用的注册确认邮件服务。
  4. 复制 Project URL 和 publishable key（或 anon key）。不要使用 secret / service_role key。

02 · 把网页放到 GitHub

  1. 创建自己的 couple-nest 仓库。
  2. 将源码包解压后的文件放在仓库根目录，确保 package.json 和 .github/workflows/pages.yml 在正确位置。
  3. Settings → Secrets and variables → Actions → Variables，添加 VITE_SUPABASE_URL 和 VITE_SUPABASE_ANON_KEY。
  4. Settings → Pages → Source 选 GitHub Actions。
  5. Actions → Publish our little nest → Run workflow。成功后打开生成的网址。
网页上传可能漏掉隐藏文件夹，可用 Add file 手动创建 .github/workflows/pages.yml，并复制源码包里对应文件内容。

03 · 邀请最喜欢的人

  1. 在 Supabase 的 Authentication → URL Configuration 中，把上线网址填入 Site URL 和 Redirect URLs。
  2. 两人分别注册、确认邮箱并登录。
  3. 一人创建小窝，另一人使用邀请链接加入，不要分别创建两个小窝。
  4. 看到「实时同步中」后，试着给对方留一句悄悄话吧。

更完整的操作说明及注意事项在源码包的 README.md。实际双设备同步需要接通服务后验证。
